# Raw dataset

Unduh dataset dari Kaggle:
https://www.kaggle.com/datasets/sudalairajkumar/cryptocurrencypricehistory

Ekstrak file CSV untuk Bitcoin, Ethereum, dan Solana ke folder ini. Script `src/prepare_kaggle_data.py` secara default mencari:

- `coin_Bitcoin.csv`
- `coin_Ethereum.csv`
- `coin_Solana.csv`

File data mentah tidak disertakan dalam repository. Lihat README utama untuk instruksi lengkap.
